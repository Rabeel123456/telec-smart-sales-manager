TELEC SMART SALES MANAGER UPDATE

This update adds only:
1. Monthly and yearly salesperson targets.
2. Monthly/yearly achievement calculations from Invoice values.
3. Closure amount/count calculated from Delivery Challans with status Delivered.
4. Direct Invoice option without a Delivery Challan.

INSTALLATION

1. Open Supabase SQL Editor.
2. Run: supabase/ADD_TARGET_CLOSURE_DIRECT_INVOICE.sql
3. Upload/replace all files from this folder in the existing GitHub repository.
4. Commit changes.
5. Wait for Vercel deployment status Ready.
6. Open the live application and press Ctrl + Shift + R.

USAGE

Sales Targets:
- A salesperson sees the Set Target button on Dashboard and can enter the current month's and year's target.
- Admin selects a salesperson from View salesperson, then presses Set Target.
- Monthly and yearly achieved values come from non-cancelled Invoices.

Closure:
- Dashboard Closure from DO is the total value and count of Delivery Challans whose status is Delivered.

Direct Invoice:
- Open Invoices > Add Invoice.
- Invoice Source has two options:
  From Delivery Challan
  Direct Invoice (Without DO)
- Direct Invoice can optionally copy a Quotation or can be entered manually.
- Saving an Invoice closes/creates its Sales Pipeline record as Won with 100% probability.
